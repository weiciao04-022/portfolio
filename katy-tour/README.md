# Katy’s Tour｜黃暐喬・報導足跡

Buildless HTML / CSS / JavaScript portfolio. All production files are in `dist/`.

## Local preview

```sh
python3 -m http.server 4173 --directory dist
```

Open http://localhost:4173.

## Editing

- `dist/index.html`: home, about, contact, and page structure.
- `dist/data.js`: 20 published works, experience, skills.
- `dist/style.css`: responsive design and visual theme.
- `dist/app.js`: filters, work details, regional routes, bookshelf, and navigation.
- `scripts/create_resume.py`: one-page A4 Chinese resume generator (ReportLab).
- `dist/assets/Katy-Huang-Resume-2026-10.pdf`: independent printable resume.

Illustrations are original SVG editorial illustrations, not documentary photography. Routes represent subject locations, not confirmed travel or actual railway service. Individual contributions and interview methods that were not supplied are identified in work details. University end dates are expected graduation dates. Awards and language proficiency are omitted because none were provided.

The digital room is a first concept and can be revised when the owner supplies their visual reference. Personal photographs can be added without changing the structure.
