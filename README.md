# Katy’s Room｜黃暐喬

純 HTML、CSS、原生 JavaScript 的互動房間作品集，不需要安裝套件或建置。
開啟即是房間；點物件看內容，關閉後回到房間。

- 矮櫃：學歷、經歷
- 書本：專題報導，右側索引切換
- 報紙／雜誌：新聞採訪作品
- 筆電：失智症／宏福苑／體態焦慮三個數位敘事分頁
- 筆記本：關於我與核心技能
- 小提琴：興趣
- 電話：學校 Email 與電話，直接使用 mailto:／tel:

房間靜態圖使用原始解析度的無損 WebP；不替換原始素材。
前 800 張 render 已壓成 `assets/room/tour.mp4`（原始 1920×1080、24fps、CRF 16），首次點擊才載入。
矮櫃、書本、雜誌與筆電恢復點擊靠近、關閉返回的鏡頭動畫；可按「略過動畫」或 Esc 直接完成轉場。其餘物件直接開啟內容。
導覽會播放目前的前 800 格（33.33 秒），最後回首頁；Esc 可結束。
手機保留完整房間比例，避免物件點擊位置因裁切錯位。
所有閱讀介面共用固定關閉按鈕及 Escape；分頁支援方向鍵、Home、End。
減少動態效果設定會略過物件鏡頭與閱讀轉場；完整導覽影片仍為主動播放。

## 預覽

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4173/。GitHub Pages 仍可從根目錄發佈。
`data.js` 的 `portfolio` 管理各物件內容，`views.js` 管理閱讀介面，`content.css` 管理閱讀樣式，`style.css` 保留房間樣式。
所有 null 內容均明確顯示「待更新」，包含簡介、分工、日期、封面及宏福苑數位作品連結。新增專題可加入 `portfolio.features`，結構為 `{id, tab, title, summary, role, image, url}`。
`app.js` 的 `clips` 管理每件物品的動畫起點、內容畫面與回程終點。

## 更新 render

素材處理工具僅用於離線壓縮，網站不需要 Python、Pillow 或 ffmpeg。
準備好 Pillow 與 ffmpeg（或 imageio-ffmpeg）後執行：

```sh
python3 scripts/prepare-room.py /Users/weiciao/Desktop/work/pic 800
```

新增完整片段後，同步更新 `app.js` 的 `clips` 與導覽結束格數。

## 內容管理規範

1. 所有文字、照片、連結和作品資訊，以使用者實際提供的素材為準。
2. 未提供的資訊統一顯示「待更新」，不得編造內容或以 AI、網路照片代替。
3. 使用者原稿不得擅自改寫、潤飾、摘要、翻譯或刪除。
4. 可以新增版面、互動及內容欄位，不能編造欄位內容。
5. 缺少照片使用標示「待更新」的圖片佔位區。
6. 缺少 Email、電話或作品連結時，不建立連結或可點擊按鈕。
7. 修改僅限指定範圍，不更改既有 3D 房間、其他文案、檔案名稱或功能。
