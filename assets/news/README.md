- 十二篇均可進入獨立閱讀並返回原版面；正式原文連結逐篇核對。
- 文字與查證頁原始段落逐一比對，科普列車與國際新聞的註解均保留。
- 標題、圖片、圖說左邊界相同；本機五張圖片正常載入並維持比例，國際版未載入任何第三方來源圖片。
- 換版支援滑鼠與鍵盤方向鍵、Home／End；Escape 沿用原本關閉並返回房間的行為。
- app.js 與其他物件資料、內容呈現皆與本次修改前一致。
